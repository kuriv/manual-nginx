# 路径匹配

精确匹配要求请求路径必须和配置路径完全一致才会命中，修改 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      80;
        server_name localhost;
        root        /usr/share/nginx/html;

        location = /admin {
            try_files   /foo.html =404;
        }

        location = /admin/ {
            try_files   /bar.html =404;
        }
    }
}
```

前缀优先匹配要求请求路径的开头部分和配置路径的前缀一致，修改 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      80;
        server_name localhost;
        root        /usr/share/nginx/html;

        location ^~ /admin {
            try_files   /foo.html =404;
        }

        location ^~ /admin/user {
            try_files   /bar.html =404;
        }
    }
}
```

正则匹配通过正则表达式匹配请求路径，修改 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      80;
        server_name localhost;
        root        /usr/share/nginx/html;

        location ~ \.JPG$ {
            try_files   /foo.html =404;
        }

        location ~* \.jpg$ {
            try_files   /bar.html =404;
        }
    }
}
```

普通前缀匹配优先级低于正则匹配，修改 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      80;
        server_name localhost;
        root        /usr/share/nginx/html;

        location /admin {
            try_files   /foo.html =404;
        }

        location /admin/user {
            try_files   /bar.html =404;
        }
    }
}
```

通用匹配优先级最低，只适用于所有路径匹配都未命中的情况，修改 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      80;
        server_name localhost;
        root        /usr/share/nginx/html;

        location / {
            index   index.html;
        }
    }
}
```
