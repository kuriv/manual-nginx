## 普通轮询

使用轮询策略来转发请求，按请求到达的时间顺序，逐一轮流分配到每台后端服务器。修改反向代理服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    upstream backend-server-pool {
        server  backend-server-foo;
        server  backend-server-bar;
        server  backend-server-baz;
    }

    server {
        listen      80;
        server_name localhost;

        location / {
            proxy_pass       http://backend-server-pool;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

分别修改后端服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      80;
        server_name localhost;

        location / {
            root    /usr/share/nginx/html;
            index   index.html;
        }
    }
}
```

## 加权轮询

使用加权轮询策略来转发请求，权重越高，分配给指定服务器的请求就越多。修改反向代理服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    upstream backend-server-pool {
        server  backend-server-foo weight=3;
        server  backend-server-bar weight=2;
        server  backend-server-baz weight=1;
    }

    server {
        listen      80;
        server_name localhost;

        location / {
            proxy_pass       http://backend-server-pool;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

分别修改后端服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
```

## IP 哈希

使用 IP 哈希策略来转发请求，同一个 IP 的请求永远分配到同一台后端服务器，会话天然粘滞。修改反向代理服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    upstream backend-server-pool {
        ip_hash;
        server  backend-server-foo;
        server  backend-server-bar;
        server  backend-server-baz;
    }

    server {
        listen      80;
        server_name localhost;

        location / {
            proxy_pass       http://backend-server-pool;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

分别修改后端服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

        listen      80;

            root    /usr/share/nginx/html;

        }
    }
```

## 最少连接数

使用最少连接数策略来转发请求，每次新请求到来时，动态分配给当前活跃连接数最少的后端服务器。修改反向代理服务器的 `nginx.conf` 配置文件内容如下。

```
worker_processes    auto;

events {
    worker_connections  1024;
```

## 状态控制

还可以控制后端服务器的状态、故障转移、限流等行为。修改反向代理服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    upstream backend-server-pool {
        server  backend-server-foo weight=3 max_fails=3 fail_timeout=10s;
        server  backend-server-bar weight=2 max_fails=3 fail_timeout=10s;
        server  backend-server-baz weight=1 max_fails=3 fail_timeout=10s;
        server  backend-server-qux backup   max_fails=2 fail_timeout=30s;
    }

    server {
        listen      80;
        server_name localhost;

        location / {
            proxy_pass       http://backend-server-pool;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

分别修改后端服务器的 `nginx.conf` 配置文件内容如下。

```
user                nginx;

events {
```
