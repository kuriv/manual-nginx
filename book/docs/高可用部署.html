高可用部署

高可用部署

准备好两台 Nginx 服务器，分别执行下面的命令，在 Ubuntu 系统中安装 Keepalived 服务。

sudo apt-get install keepalived

安装完成后，执行下面的命令检查 Keepalived 服务运行状态。

sudo systemctl status keepalived

分别在两台服务器中创建脚本文件 /etc/keepalived/check_nginx.sh 内容如下。

#!/bin/bash
LOG_FILE="/var/log/check_nginx.log"
NGINX_PORT=80
FAIL_FLAG="/tmp/nginx_start_fail.flag"

if [ ! -f "$LOG_FILE" ]; then
    touch "$LOG_FILE"
    chmod 777 "$LOG_FILE"
fi

log() {
    echo "[$(date +'%Y-%m-%d %H:%M:%S')] $1" >> "$LOG_FILE"
}

check_nginx_process() {
    if ps -ef | grep -v grep | grep -q "nginx: master process"; then
        return 0
    else
        return 1
    fi
}

check_nginx_port() {
    if curl -s -o /dev/null -w "%{http_code}" "http://127.0.0.1:$NGINX_PORT" | grep -q "200\|301\|302"; then
        return 0
    else
        return 1
    fi
}

start_nginx() {
    log "尝试启动 Nginx..."
    systemctl start nginx
    sleep 3
}

log "===== 开始检测 Nginx 状态 ====="

if [ -f "$FAIL_FLAG" ]; then
    log "检测到 Nginx 启动失败标记文件，关闭 Keepalived 触发 VIP 切换."
    systemctl stop keepalived
    exit 1
fi

if check_nginx_process && check_nginx_port; then
    if [ -f "$FAIL_FLAG" ]; then
        rm -f "$FAIL_FLAG"
        log "Nginx 恢复正常，删除失败标记文件."
    fi
    log "Nginx 运行正常."
    exit 0
else
    log "Nginx 未正常运行，开始处理..."
    start_nginx
    if check_nginx_process && check_nginx_port; then
        log "Nginx 重新启动成功."
        exit 0
    else
        touch "$FAIL_FLAG"
        log "Nginx 启动失败，创建标记文件,关闭 Keepalived 触发 VIP 切换."
        systemctl stop keepalived
        exit 1
    fi
fi

然后给创建好的脚本文件添加执行权限。

sudo chmod +x /etc/keepalived/check_nginx.sh

修改主节点服务器的 /etc/keepalived/keepalived.conf 配置文件如下。

vrrp_script check_nginx {
    script "/etc/keepalived/check_nginx.sh"
    interval 5
    weight -20
}

vrrp_instance VI_1 {
    state MASTER
    interface ens33
    virtual_router_id 51
    priority 100
    advert_int 1
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    virtual_ipaddress {
        192.168.10.100
    }
    track_script {
        check_nginx
    }
}

修改备节点服务器的 /etc/keepalived/keepalived.conf 配置文件如下。

vrrp_script check_nginx {
    script "/etc/keepalived/check_nginx.sh"
    interval 5
    weight -20
}

vrrp_instance VI_1 {
    state BACKUP
    interface ens33
    virtual_router_id 51
    priority 80
    advert_int 1
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    virtual_ipaddress {
        192.168.10.100
    }
}

先关闭 Nginx 服务，随后重启 Keepalived 服务，再分别执行 /etc/keepalived/check_nginx.sh 脚本文件。一切配置已准备就绪，执行下面的命令，配置成功的情况下只有主节点服务器中有虚拟 IP ，而备节点服务器中则没有，通过访问虚拟 IP 即可查看效果。

ip addr

在主节点服务器中执行下面的命令，模拟主节点服务器故障。

sudo systemctl stop keepalived
sudo systemctl stop nginx

此时，主节点服务器发生故障，系统将自动切换到备节点服务器。而当故障恢复后，则会自动切换回至主节点。
