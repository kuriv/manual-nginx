# 虚拟主机

还可以通过配置端口号访问指定的 Web 服务，修改 `nginx.conf` 配置文件内容如下。

```
user                nginx;
worker_processes    auto;

events {
    worker_connections  1024;
}

http {
    include         mime.types;
    default_type    application/octet-stream;

    server {
        listen      8001;
        server_name localhost;

        location / {
            root    /usr/share/nginx/html/8001;
            index   index.html index.htm;
        }
    }

    server {
        listen      8002;
        server_name localhost;

        location / {
            root    /usr/share/nginx/html/8002;
            index   index.html index.htm;
        }
    }
}
```
